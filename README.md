# 🏛️ 3D Интерактивная Арт-Галерея

Интерактивный 3D-выставочный зал на Three.js для демонстрации картин и авторских графических работ.

---

## 🚀 Быстрый запуск

### Вариант 1. Запуск в 1 клик (Рекомендуется для ПК и телефонов)
Дважды кликните по файлу:
```text
start.bat
```
* Сервер автоматически запустится на базе Node.js.
* В браузере вашего компьютера сразу откроется галерея: `http://localhost:3000`.
* В консоли отобразится ссылка для смартфонов и планшетов:
  ```text
  📱 На смартфоне / планшете (в сети Wi-Fi):
     👉 http://192.168.1.68:3000
  ```

---

## 📱 Просмотр на телефоне или планшете
1. Убедитесь, что ваш телефон и компьютер подключены к одной сети Wi-Fi.
2. В интерфейсе галереи на ПК нажмите кнопку **«📱 На телефон»** в верхнем правом углу.
3. Наведите камеру смартфона на появившийся **QR-код** или введите адрес вручную в браузере телефона.
4. Галерея откроется прямо на мобильном устройстве:
   * **Движение**: виртуальные кнопки со стрелками в левом нижнем углу.
   * **Обзор**: проведение пальцем по экрану (свайпы).
   * **Осмотр картин**: просто коснитесь любой картины на стене, чтобы открыть её во весь экран.

## 🎮 Управление на компьютере
* **WASD** или **Стрелки ↑ / ↓** — перемещение по залу
* **Мышь** или **Стрелки ← / →** — поворот головы и панорамный обзор
* **ЛКМ (клик по картине)** — приблизить и рассмотреть картину
* **F** — полноэкранный режим
* **Esc** — выход из режима просмотра картины

---

## 📂 Структура проекта
* **`gallery.html`** — главное приложение (3D-сцена, физика, освещение, интерфейс).
* **`server.js`** — локальный HTTP-сервер на чистом Node.js (авто-сканирование папки, чтение каталога, определение IP в Wi-Fi).
* **`paintings.json`** — каталог экспозиции (названия, регионы/жанры, даты создания и техника для каждой картины).
* **`start.bat`** — скрипт быстрого запуска для Windows.
* **`*.jpg`** — коллекция картин (46 авторских работ).

---

## 🎨 Настройка названий, дат и описаний (`paintings.json`)

Вы можете в любой момент изменить название, географическую привязку/жанр, дату создания или технику исполнения любой картины:

1. Откройте файл [**`paintings.json`**](file:///c:/01_AI%20Coding/Art%20Galery/paintings.json) в обычном Блокноте (или любом текстовом редакторе).
2. Найдите нужную картину по имени файла и отредактируйте параметры:
   ```json
   "Trakai2.jpg": {
       "title": "Замок Тракай",
       "subtitle": "Литва • Островной замок",
       "date": "Октябрь 2025 г.",
       "technique": "Оригинальная работа • Акварель, тушь"
   }
   ```
3. Сохраните файл и просто обновите страницу в браузере (**F5**) — перезапускать сервер не требуется!

### ➕ Добавление новых картин:
* Просто скопируйте новый файл `.jpg` или `.png` в папку галереи.
* Сервер автоматически распознает его, сгенерирует аккуратные параметры по умолчанию и сам добавит запись в `paintings.json`.
* После этого вы сможете открыть `paintings.json` и при желании уточнить название или дату.
