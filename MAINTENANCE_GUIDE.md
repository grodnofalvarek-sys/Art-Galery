## 🔄 3. Как внести изменения и обновить сайт в интернете

Любые изменения (исправление опечатки, корректировка названия картины, изменение цвета или освещения) публикуются в интернет в 3 простых действия через **GitHub Desktop**:

### Шаг 1: Отредактируйте нужный файл на компьютере
* Если правите код или интерфейс — редактируйте **`index.html`** (и скопируйте в `gallery.html`).
* Если правите метаданные (название, год, технику) — редактируйте **`index.html`** (массивы `DEFAULT_PAINTINGS` и `CATALOG_EN`) и **`paintings.json`**.

### Шаг 2: Откройте GitHub Desktop
* Приложение само моментально увидит изменённые файлы и подсветит их жёлтыми точками.
* В левом нижнем углу в поле **Summary** напишите краткое описание изменений (например: *«Исправление названия картины»* или *«Обновление интерфейса»*).
* Нажмите синюю кнопку **`Commit to main`**.

### Шаг 3: Отправьте изменения в интернет
* В верхней панели GitHub Desktop нажмите кнопку **`Push origin`** (или комбинацию `Ctrl + P`).
* **Всё!** Через 30–60 секунд сайт `https://grodnofalvarek-sys.github.io/Art-Galery/` автоматически обновится.

## ➕ 4. Как добавить новую картину в коллекцию

1. **Скопируйте новый файл** `.jpg` или `.png` в корень папки `Art Galery`.
2. **Сгенерируйте миниатюру**:
   * Либо запустите `start.bat` (сервер сам заметит новый файл и автоматически сделает миниатюру в папку `thumbs/`).
   * Либо запустите PowerShell-скрипт `generate-thumbs.ps1`.
3. **Добавьте описание в `index.html`**:
   * В массив `DEFAULT_PAINTINGS` добавьте строку с русским названием:
     ```javascript
     { "name": "NewWork.jpg", "url": "thumbs/NewWork.jpg", "fullUrl": "NewWork.jpg", "title": "Название картины", "subtitle": "Регион • Сюжет", "date": "Месяц ГГГГ г.", "technique": "Техника исполнения" }
     ```
   * В объект `CATALOG_EN` добавьте английский перевод:
     ```javascript
     "NewWork.jpg": { title: "English Title", subtitle: "Region • Theme" }
     ```
4. **Сделайте Commit & Push** в GitHub Desktop — новая картина сразу появится на стенах ротонды!

## 🛡️ 5. Как мгновенно откатить изменения при багах

Если в процессе экспериментов что-то пошло не так (сломалась геометрия, пропал свет или возникла ошибка в JavaScript), вы можете вернуться к стабильному состоянию в 1 клик.

### Мгновенный откат к золотой версии публикации (`stage3_published_golden`):

Откройте PowerShell в папке проекта и выполните одну команду:
```powershell
Copy-Item -Path "backups\stage3_published_golden\*" -Destination "." -Force
```
Эта команда восстановит эталонные версии `index.html`, `gallery.html`, `paintings.json` и `server.js`.

### Доступные точки восстановления:
1. **`stage3_published_golden`** — **Золотой эталон**: всё протестировано, чистый пол, кнопки «Поделиться» и «Помощь», переключение языка RU/EN, 46 полотен на стенах.
2. **`stage5_pre_i18n`** — состояние до внедрения модуля двуязычия (чистый русский язык).
3. **`stage5_nav_pre`** — состояние до переработки управления мышью и стрелками.
4. **`stage4_completed`** — стабильная база этапа 4 с миниатюрами.

## 📱 6. Горячие клавиши для проверки в браузере

* **F5** или **Ctrl + R** — обновить страницу.
* **Ctrl + F5** (или **Ctrl + Shift + R**) — жёсткое обновление страницы с очисткой кэша браузера (полезно, если браузер держит старый кэш после публикации).
* **F12** — консоль разработчика (вкладка Console покажет красные ошибки, если в JavaScript допущена опечатка).
